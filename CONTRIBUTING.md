# Contributing

English | [中文](CONTRIBUTING.zh.md)

This independent edition welcomes reports, proposals, and pull requests about its desktop experience and the Harness capabilities that support it.

## Before contributing

- Search [Issues](https://github.com/midnight-automaton/deepseek-harness/issues) for an existing report. Open an issue before a broad behavior or architecture change.
- Follow [AGENTS.md](AGENTS.md) and the [development guide](docs/development.md) for repository conventions and local checks.
- Keep changes focused. Update the relevant tests and English/Chinese documentation when behavior changes.
- Do not commit credentials, local sessions, installed dependencies, or build output. The root [`.gitignore`](.gitignore) covers normal generated files.

The original Harness project is maintained at [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness). Report upstream-only issues there; use this repository for changes specific to this edition.
